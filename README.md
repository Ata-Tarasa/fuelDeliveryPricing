# How To Run
## 1. Requirements
  1.1 Installed openJDK version 17 or higher;</br>
  1.2 Installed Apache Maven version 3.8 or higher;
## 2. Compilation
  2.1 Clone this repository;</br>
  2.2 Go to the directory where the `pom.xml` file is located (`fuelDeliveryPricing/fuel_delivery_pricing/`);</br>
  2.3 Run the command `mvn package`;</br>
  2.4 Two files will appear: `fuel-delivery.jar` and `fuel-delivery` executable (or `fuel-delivery.bat` if compiled on Windows)</br>
## 3. Running
  3.1 Run the command `./fuel-delivery` (Unix) or `.\fuel-delivery.bat` (on Windows) to start the program
